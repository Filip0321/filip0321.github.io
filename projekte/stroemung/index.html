Start

Auf dem Bild ziehen rührt um und gibt Tinte dazu.

Tinte und Strahlen
Flüssigkeit

„Druck-Schritte“: wie genau die Flüssigkeit inkompressibel gehalten wird (mehr = genauer, langsamer). „Wirbel verstärken“ gibt die kleinen Wirbel zurück, die die Rechnung sonst verwischt.

Aussehen

Strömungslinien (Line Integral Convolution): jeder Pixel mittelt ein Rauschen entlang seiner Stromlinie. Was auf derselben Linie liegt, wird gleich hell, quer dazu wechselt es: Striche genau in Fließrichtung, wie Eisenfeilspäne. Kostet viel Grafikkarte: auf schwachen Geräten die Linienlänge klein lassen.

Musik

Bass macht die Strahlen stärker, ein Schlag spritzt Tinte an eine zufällige Stelle; dazu können Wirbel und Farbe der Musik folgen. „Video rendern“ geht mit einer Musikdatei; sie ist dann der Ton des Videos.
